# Light novel art direction

The default onboarding illustration is AI-generated cover artwork, not a saved user character. It is stored in `frontend/public/images/default-cover.png` and rendered by `frontend/src/WorldIllustration.tsx`.

Replace `frontend/public/images/default-cover.png` with another PNG to change the default cover for this installation; restart/rebuild the frontend for a production build. Each user can also upload a world-specific PNG/JPEG during setup or use **Change cover** on the saved world's dashboard. Custom covers are saved by the backend and take precedence over the default. Changing the shared default does not replace users' custom covers.

Created with the built-in image generation tool. The page uses a light paper-and-sky palette, character-centered anime artwork, and novel-inspired typography.

## Generation prompt

Use case: illustration-story. Asset type: portrait hero artwork for Script, an isekai light-novel-inspired habit tracker. Create an original Japanese light novel cover illustration WITHOUT ANY TEXT. Portrait composition about 4:5. Scene: a young adult traveler newly arrived in an unfamiliar world, standing on a sunlit overlook above a lively fantasy city, looking back toward the viewer with an intrigued, hopeful expression. Clearly visible expressive anime face, windswept dark hair, simple contemporary shirt under a lightweight blue travel jacket, small shoulder satchel: an ordinary person at the beginning of an extraordinary story, not an armored wizard. Behind them: terracotta rooftops, a distant slender castle, green countryside, vast blue sky and billowing white summer clouds. A paper map lightly held in one hand. Style: polished contemporary light novel color frontispiece, refined anime linework, beautiful character drawing, delicate watercolor-like environmental detail, soft cel shading, airy atmospheric perspective, crisp detailed eyes. Mood: youthful adventure, possibility, discovery, a fresh start. Palette: luminous sky blue, ivory, fresh greens and soft coral. Frame waist-up or mid-thigh, protagonist prominent in the lower/right-middle with the fantasy city and sky still visible; composition must work when cropped to a tall webpage panel. Avoid: glowing portals, runes, magic circles, dark gothic atmosphere, giant weapons, generic geometric vector art, 3D, photorealism, UI, borders, letters, logos, typography, watermarks. Original character and world; no existing franchise.
