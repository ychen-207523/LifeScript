# Default world cover

`default-cover.png` is Script's shared fallback cover. Replace this file with your own PNG to customize it for this installation, then refresh the development preview or rebuild the frontend for production. A portrait image around 4:5 works well; the layout crops other proportions to fit.

Users can also choose **Use your own cover** while creating a world, or **Change cover** on its dashboard. Those covers are stored per world on the backend and override this shared default. Supported uploads: PNG/JPEG, at most 5 MB, at most 4096 pixels per side and 8 megapixels.

The included cover was created with the built-in image generation tool. Its prompt and provenance are documented in `docs/art-direction.md` at the repository root.
